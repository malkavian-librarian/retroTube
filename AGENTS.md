# Agent Instructions

This repo builds the Weekly Retro Tool. Before doing any work, pull context from these docs — don't guess at product behavior, architecture, or process:

- **`_docs/process.md`** — how work is tracked and how to pick up a task: tasks live as GitHub issues, how to read/close against acceptance criteria, commit conventions, and the full map of `_docs/` files. Read this first.
- **`_docs/tasks.md`** — the original task backlog the GitHub issues were generated from. Superseded by the issues themselves for current status, but useful for the full list/ordering of planned work.
- **`_docs/weekly-retro-mvp.md`** — the product spec. Read this to understand what the app should *do*, section by section (Create, Join, Write, Reveal, Vote, Discuss, Actions, Close, Deletion).
- **`_docs/arch.md`** — the architecture reference. Read this to understand *how it's built*: stack choices, Django app layout, data model sketches, the realtime event contract, coding standards, and deployment notes.

Work one GitHub issue at a time. See `_docs/process.md` for the full workflow.
